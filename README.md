# JRobs Journal

Native SwiftUI Bible journaling app for iPhone, iPad, and Mac.

## Open in Xcode

1. Open `JRobsJournal.xcodeproj` in Xcode 16 or newer.
2. Select the `JRobsJournal` scheme.
3. Choose an iPhone, iPad, or **My Mac (Designed for iPad)** destination.
4. Press **Run**.

## Current foundation

- Adaptive `NavigationSplitView` interface
- Old and New Testament book folders
- One-word Bible-book search
- Persistent freehand journal entries
- Per-book note creation
- System, light, and dark appearance settings
- Reader text-size preference
- Bible map placeholder for licensed map assets

Bible text and map content are intentionally not bundled until a legally licensed source is selected.
